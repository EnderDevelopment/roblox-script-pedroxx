# Roblox Scripts

This project is a collection of Roblox scripts designed to enhance gameplay and provide additional functionality within Roblox games. The scripts are written in Lua and can be easily integrated into Roblox Studio projects.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `ServerScriptService` folder in the Explorer.
4. Right-click on the `ServerScriptService` folder and select `Insert Object`.
5. Choose `Script` from the list of objects.
6. Name the script appropriately (e.g., `KeyPressPartCreator`).
7. Copy and paste the script code from the respective file into the script in Roblox Studio.
8. Save the place.

## Use

1. Launch the Roblox game in Roblox Studio.
2. Press the 'e' key to create a part in front of the player's character.
3. The part will be anchored and will not move.
